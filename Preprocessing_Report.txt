EcoPredict AI — Data Preprocessing Report
========================================

Input file: Fuel_Consumption.csv
Output file: Final_Data_Preprocessed.csv

Preprocessing rule:
- Kept the first occurrence of each exact row.
- Removed only rows where BOTH Engine size (L) and CO2 emissions (g/km)
  exactly matched a previous row.
- Did not change or invent any feature or target values.
- Did not remove rows just because engine size matched if CO2 emissions differed.
- The original CSV remains unchanged.

Important limitation:

or vehicle IDs. Therefore, exact repeated pairs cannot be proven to be erroneous
records. This cleaned file should be described as an "exact-duplicate-removed
experimental dataset", not automatically as a universally better dataset.
