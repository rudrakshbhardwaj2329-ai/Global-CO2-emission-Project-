# EcoPredict AI 🌱

**Vehicle CO₂ Emission Prediction using Simple Linear Regression**

A beginner-friendly first-year ML project that predicts vehicle CO₂ emissions using engine size.

## What we will do
1. Load a real vehicle emissions dataset.
2. Plot engine size against CO₂ emissions.
3. Train a Simple Linear Regression model.
4. Predict emissions for an engine size.
5. Evaluate the model using MAE and R².
